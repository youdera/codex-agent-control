# Skin artwork

`skins/miku/character.png` and its copy in `skins/miku-night/` are an AI-generated, non-official Hatsune Miku fan illustration made with the built-in OpenAI image generation tool. They are decorative, optional and replaceable.

The request described a cheerful, modestly dressed Miku holding a small tablet, with turquoise twin tails and a transparent background. No user photograph, game asset, private screenshot or API material was used.

The software MIT license does **not** grant rights in the character or this fan artwork. Character-related rights remain with their respective holders. Remove/replace the PNG files or select the `work` skin to use the dashboard without this illustration. No official affiliation or endorsement is claimed.

Skin manifests contain declarative colors, density and local image paths. They do not load JavaScript modules or remote assets.
